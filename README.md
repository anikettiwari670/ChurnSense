# ChurnSense

A machine learning application for telecom customer churn
prediction and analytics.

## Features

- Customer churn KPI dashboard
- Individual customer churn prediction
- Batch prediction from CSV uploads
- Downloadable prediction results
- Model analytics

## Tech Stack

- Python
- Pandas
- Scikit-learn
- Streamlit
- Plotly

## Run Locally

Install dependencies:

pip install -r requirements.txt

Run the application from the project root:

streamlit run app/streamlit_app.py

## Deployment

Push the project to GitHub and deploy the repository through
Streamlit Community Cloud.

Select app/streamlit_app.py as the application entry point.
